# AI 기반 IoT 스마트 옷장 기획서

## 1. 프로젝트 개요

### 프로젝트명
AI Smart Closet

### 목적
RFID와 AI를 이용하여 보유 의류를 자동으로 관리하고, 사용자의 일정·날씨·취향에 맞는 코디를 추천하며, 선택된 의류를 최적의 착용 상태로 준비하여 자동으로 인출해주는 IoT 옷장을 구현한다.

---

## 2. 핵심 시스템 구조

```
RFID 의류 식별
      ↓
의류 데이터베이스
      ↓
AI 코디 추천
      ↓
Smart Cell 위치 확인
      ↓
의류별 환경 관리
      ↓
Wear-Ready Conditioning
      ↓
선택 의류 자동 인출
```

---

## 3. RFID 기반 의류 관리

각 의류 또는 전용 옷걸이에 RFID 태그를 부착한다.

RFID별 데이터베이스에 다음 정보를 저장한다.

- 의류 종류
- 색상
- 소재
- 계절
- 두께
- 스타일
- 보관 위치
- 최근 착용일
- 착용 횟수
- 세탁/관리 상태
- 소재별 관리 프로파일

카메라는 상시 의류 인식보다 신규 의류 등록 시 종류·색상 등의 정보를 입력하는 보조수단으로 사용한다.

---

## 4. Smart Cell 개별 의류 관리

옷장을 여러 개의 파티션(Smart Cell)으로 구성하여 각 의류를 독립적으로 보관한다.

각 Cell에는 다음 기능을 적용한다.

- RFID 식별
- 온·습도 측정
- 공기 유량 조절
- 개별 댐퍼 제어
- 상태 표시 LED
- 의류 인출용 캐리지

중앙의 공조장치를 여러 Cell이 공유하여 부품 수와 소비전력을 줄인다.

```
중앙 공조 시스템
   │
   ├─ Cell 1
   ├─ Cell 2
   ├─ Cell 3
   └─ Cell N
```

---

## 5. 의류 맞춤 관리 기능

RFID를 통해 확인된 소재에 따라 각 의류에 적합한 관리 조건을 적용한다.

### Storage Care
장기간 보관 시 의류 상태 유지가 목적이다.

- 온·습도 관리
- 제습
- 공기 순환
- 필요 시 Refresh
- 이상 습도 감지

### Wear-Ready
착용 직전 사용자의 쾌적성이 목적이다.

- 여름 → 안전범위 내 냉각 및 제습
- 겨울 → 안전범위 내 예열
- 장마철 → 제습 중심 관리
- 소재에 따라 온도·풍량 자동 제한

AI는 관리 방법을 직접 결정하기보다 미리 정의된 소재별 안전범위 안에서 적절한 조건을 선택한다.

---

## 6. AI 코디 기능

AI는 다음 데이터를 이용해 착장을 추천한다.

- 현재 옷장에 존재하는 의류
- 날씨
- 계절
- 사용 목적
- 사용자 취향
- 최근 착용 기록
- 세탁 상태
- 의류 사용 빈도

외부 디스플레이에서 여러 코디를 제안하고 사용자가 원하는 코디를 선택한다.

---

## 7. 선택 의류 자동 인출

로봇팔 대신 옷걸이 캐리지 + 공용 이동 셔틀 구조를 사용한다.

```
CELL 1  [셔츠]
CELL 2  [재킷]
CELL 3  [팬츠]
CELL 4  [코트]
=====================
   공용 이동 셔틀
←────────────────→
          │
          ▼
       의류 인출구
```

AI 코디 선택 후:

1. RFID DB에서 선택 의류 위치 확인
2. 해당 Cell에서 Wear-Ready 실행
3. 공용 셔틀이 해당 Cell로 이동
4. 옷걸이 캐리지를 인출구 방향으로 이동
5. 사용자가 의류를 꺼냄
6. RFID 부재를 확인하여 착용 상태로 변경

이를 통해 복잡한 로봇팔 없이 적은 수의 모터로 여러 의류를 자동 선택할 수 있다.

---

## 8. 추가 소프트웨어 기능

기존 센서와 RFID 데이터를 재사용하여 다음 기능을 구현한다.

- 착용 횟수 자동 기록
- 세탁 주기 관리
- 휴면 의류 탐지
- 자주 입지 않은 옷 우선 코디
- 사용자 코디 선택 패턴 학습
- 의류 위치 검색
- Cell 상태 LED 안내
- 이상 온·습도 감지
- 공조장치 이상 진단
- 필요한 Cell만 동작시키는 에너지 절약 제어

---

## 9. 외출 준비 자동화

사용자가 외출시간 또는 외출 준비 버튼을 설정하면 전체 기능을 자동 연계한다.

```
외출 예정
   ↓
날씨 확인
   ↓
AI 코디 추천
   ↓
사용자 코디 선택
   ↓
RFID 위치 확인
   ↓
선택 의류 Wear-Ready
   ↓
준비 완료 알림
   ↓
자동 인출
```

---

## 10. 핵심 차별점

기존 스마트 옷장의 단순한 의류 보관 또는 AI 코디 추천을 넘어,

> 의류 식별 → 관리 → 코디 → 착용 준비 → 실제 의류 인출

까지 하나의 시스템으로 연결한다.

### 핵심 기술 구성

RFID + Smart Cell + 중앙 공조 + AI 코디 + Wear-Ready + 자동 의류 인출 + 외부 디스플레이

이를 통해 적은 하드웨어 자원으로 의류관리와 사용자 편의성을 동시에 높이는 자동화 스마트 옷장을 목표로 한다.
